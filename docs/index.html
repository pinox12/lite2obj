Qué hace

Fiel a Minecraft, cómodo en Blender.

No es un conversor de cajas: respeta blockstates, variantes, rotaciones, UVs, transparencia, tintes de bioma y las reglas de culling del juego.

Malla fiel al juego

Blockstates, multipart, herencia de modelos, rotaciones de variant y de elemento, UVs explícitas y uvlock como vanilla.

Atlas y tintes

Empaqueta todas las texturas en un atlas con padding y modos de transparencia. Césped, hojas y agua con su color de bioma.

Culling de verdad

Descarta caras contra cubos opacos, cristal del mismo tipo, vidrieras y vallas. Los fluidos comparten altura de esquina y forman rampas continuas.

Entidades y block entities

Cofres, estandartes, calaveras, marcos, barcos, vagonetas y criaturas opcionales, con las matrices y poses de vanilla.

Listo para Blender

OBJ con caras cuadriláteras, MTL con un material atlas y el PNG del atlas. Sin pasos intermedios ni plugins.

App y CLI

Visor 3D con órbita, rejilla, wireframe y corte por capas, o comandos info, list y export para automatizar.

Cómo funciona

Tres pasos y ya estás en Blender.

La app no busca instalaciones de Minecraft ni esquemáticos por el disco. Tú eliges los archivos; ella hace el resto.

Abre tu .litematic

Arrástralo sobre la ventana o usa Abrir esquemático…. Verás la malla en el visor 3D antes de exportar.

Genera el pack de assets

Elige tu client.jar una vez. lite2obj extrae blockstates, modelos y texturas a un .l2oassets local.

Exporta a OBJ

Elige carpeta y nombre. Importa el .obj en Blender con el .mtl y el atlas.png al lado.

Assets sin líos

Las texturas no viajan en la build.

Las builds de GitHub Releases se publican sin lite2obj-assets.l2oassets ni texturas de Minecraft: el contenido tiene derechos de autor y cada usuario genera su propio archivo desde el jar de su versión.

Es un paso único. Después, lite2obj usa ese pack en todos los renders, sin volver a pedir el jar ni escanear el disco.

  • Sin autodetección de Minecraft, versiones ni resource packs.
  • Resource packs opcionales, añadidos a mano como .zip o carpeta.
  • Aviso ⚠ si el esquemático trae bloques que no están en el pack.
⚠
¿Bloques omitidos? El pack es anterior a tu esquemático. Regenera los assets con un client.jar más reciente desde Archivo → Generar archivo de assets….
terminal 
# Desde la app
Archivo → Generar archivo de assets…

# O desde la CLI
$ uv run lite2obj assets build --jar client.jar
$ uv run lite2obj assets info

# Exportar el esquemático
$ uv run lite2obj export casa.litematic salida/ --name casa

Preguntas frecuentes

Lo que suele hacer falta saber.

¿Necesito tener Minecraft instalado?

No. Solo necesitas el client.jar de la versión que uses para generar el archivo de assets una vez. lite2obj no busca instalaciones, lanzadores ni carpetas de Minecraft en el disco.

¿Dónde se guarda el archivo .l2oassets?

En Linux, en ~/.local/share/lite2obj/. En Windows, en %LOCALAPPDATA%\lite2obj\. También puedes indicar una ruta concreta con la variable LITE2OBJ_ASSET_PACK.

El panel muestra ⚠ y faltan bloques. ¿Qué hago?

Significa que el esquemático usa bloques que no están en tu pack (normalmente de una versión más nueva). Regenera los assets con un client.jar reciente desde Archivo → Generar archivo de assets…. Los bloques que no se puedan resolver se omiten; el resto del esquemático se renderiza igual.

¿Puedo usar resource packs?

Sí. Añádelos a mano con Añadir .zip… (puedes seleccionar varios) o Añadir carpeta…. Se activan con casillas y se ordenan por prioridad. No se buscan packs por el disco.

¿Cómo abro un .litematic con doble clic?

Desde la app: Archivo → Asociar archivos .litematic…. En Linux crea una entrada .desktop y el MIME en tu perfil; en Windows escribe las claves de HKCU\Software\Classes. No hace falta administrador y se puede deshacer desde el mismo menú.

¿Por qué la build de GitHub no trae texturas?

Porque los assets de Minecraft tienen derechos de autor. El repositorio y las releases solo publican el código y los ejecutables; el archivo de assets se genera en tu máquina a partir de tu propio jar.

¿Cómo compilo la app desde el código?

Instala uv, ejecuta uv sync y luego uv run lite2obj gui. Para generar la AppImage o el .exe, usa los scripts de packaging/. Las instrucciones completas están en el README del repositorio.
